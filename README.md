# Yanbei Chen — personal website

## 文件说明

| 文件 | 内容 |
|---|---|
| `index.html` | 首页：简介、研究方向、近期动态 |
| `research.html` | 研究主线、发表、报告 |
| `teaching.html` | 教学理念、课程、指导 |
| `portfolio.html` | 设计作品集 |
| `styles.css` | 全站样式（颜色在文件最上面的 `:root` 里改） |
| `assets/` | 照片、截图、CV PDF |

## 常见修改

- **换 CV**：把新的 PDF 命名为 `Yanbei-Chen-CV.pdf`，上传到 `assets/`，覆盖旧文件。
- **加照片**：上传 `assets/photo.jpg`，然后在 `index.html` 里找到 `PHOTO` 注释，按说明替换。
- **加动态 / 发表 / 截图**：每个列表上方都有注释（`<!-- ... -->`），复制一条 `<li>...</li>` 改文字即可。
- **只改尖括号 `< >` 之间的文字**，不要删标签本身。

在 GitHub 网页上打开文件 → 点铅笔图标编辑 → 点 "Commit changes" 保存，网站会在 1–2 分钟内自动更新。
